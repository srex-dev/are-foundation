# ARE Foundation v0.1.0

Initial Apache-2.0 foundation release.

## Included

- Public S0/S1 gateway and REST BFF.
- Agent registration basics.
- Scoped passport issuance and verification.
- Scope evaluation.
- Policy evaluation.
- Immutable ledger/proof-root foundation pieces.
- Public OpenAPI slice.
- Docker Compose local runtime.
- Public-safe smoke, gate, pressure, and pressure-matrix runners.
- Examples for model promotion check-only, data access policy checks, and agent passport lifecycle.

## Not Included

- Command Center or `/control`.
- Visual RAG, client demo frontend, BYOPolicy commercial UX, or public policy-pack UX.
- Synthetic client emulator or private `.are-gates` proof packets.
- S2-S6 adaptive stages.
- Governance-strata internals.
- Customer action execution.

## Boundary

ARE Foundation evaluates authority and policy. It does not execute customer actions by default, does not create customer-action receipts, and does not claim certification, production readiness, or full ARE governance coverage.

## Verification

Before publishing, run:

```bash
make test
make gate
make up
make smoke
make pressure-matrix
make down
```
