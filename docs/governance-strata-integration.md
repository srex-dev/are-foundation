# Governance-Strata Integration Hook

Governance-strata is not included in ARE Foundation.

The integration point is conceptual:

1. ARE Foundation proves actor identity, scoped authority, and policy outcome.
2. A higher-risk system can wrap promotion, activation, or execution transitions with additional governance-strata checks.
3. The commercial ARE platform adds deeper stage gates, operator RAG, visual evidence, replay, and governed admin flows.

In this repo, those later-stage transitions should remain docs-only.
