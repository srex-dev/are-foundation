# Public Boundary

ARE Foundation is the S0/S1 public runtime:

- register an actor
- issue scoped authority
- evaluate scope
- evaluate policy
- return public-safe proof basics

It does not execute customer actions. All examples and proof summaries use `executed=false`.

Not included:

- Command Center
- visual RAG
- client demo frontend
- BYOPolicy commercial UX
- private proof packets
- advanced adaptive stages
- governance-strata internals

Governance-strata is an integration concept for higher-risk transitions in the commercial ARE platform. It is not bundled here.
